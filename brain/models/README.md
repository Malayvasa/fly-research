# Meadow learned visual driver

This is a separate learned steering decoder over simulated visual neurons.
It is **not** steering generated by the fly's descending motor circuits.
The fixed MaleCNS simulation, its external Fly64 dependency, and the existing
motor-output mode remain separate from these learned weights.

The model manifest records the exact weight hash and two successful three-lap
checks with zero assisted recoveries. Earlier failures are documented in
`docs/trained-readout.md`; this is a circuit-specific experimental baseline,
not a general driving model or evidence of biological driving ability.

After installing the dependencies and preparing the pinned neural dataset:

```sh
.venv/bin/python -m brain.server --fly64 .cache/fly64 --readout brain/models/meadow-visual-readout.npz
npm run dev -- --port 5173 --strictPort
```

Open `http://127.0.0.1:5173/?opponent=fly&readout=trained` for the learned
visual driver. Omit `readout=trained` for the fly motor-output path. Both
currently use assisted throttle; only the learned mode has the 8 m/s cutoff.

Training uses game-camera examples and offline expert targets generated by
this project. The model depends on the MaleCNS data described and attributed
in `docs/fly-controller-handoff.md`. No upstream Fly64 source is bundled here;
its reuse/distribution terms still need resolution before distributing that
dependency. The learned decoder does not replace the external simulation.
